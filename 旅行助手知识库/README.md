## 这是什么

本知识库收录旅行规划相关的领域知识，供旅行助手 Agent 在回答用户问题时检索引用。内容按主题拆分为独立 md 文档，结构上适合直接作为 RAG 语料（按标题/小节切块 → 向量化入库）。

## 信息可信度分级

资料来自公开网络检索（tavily），按来源质量分级：

- **官方确认**：政府/使领馆/铁路/旅游局官网（如 nia.gov.cn、visaforchina.cn、12306.cn、各国驻华使馆）——签证、高铁规则、安全须知等时效性强的内容以此为准
- **行业信息**：主流平台/机构报告（Expedia、Skyscanner、去哪儿、中国旅游研究院等）——机票规律、预算参考等
- **经验总结**：旅游社区/攻略类内容——玩法、美食、避坑经验

> ⚠️ 签证、价格类信息时效性强，政策可能随时调整。Agent 引用时需结合当前日期判断，重要决策（办签证、买机票）前应引导用户到官方渠道二次确认。
