# 09 打包清单

> 更新时间：2026-08-18 ｜ 来源：Trip.com/Holafly/Hostelworld 打包清单（行业信息+经验总结）

## 一、通用基础清单

### 证件与支付（最重要，随身携带）
- 身份证（国内）/ 护照（出境，有效期 ≥6 个月）
- 签证/入境许可（如需）
- 机票/车票订单、酒店订单（打印或存手机）
- 信用卡/银行卡（至少两张，不同银行）、适量现金（分开放）
- 证件复印件 + 电子备份（详见《08 旅行安全》）
- 学生证（国内景区半价）、驾照+翻译件（自驾）

### 电子设备
- 手机 + 充电器 + 数据线（备两根）
- 充电宝（必须随身，容量注意航司限制，一般 ≤20000mAh/100Wh）
- 转换插头（出境：欧标/美标/英标/日标不同）
- 耳机、相机（可选）、eSIM/境外流量卡（提前开通）

### 衣物鞋履
- 按天数×换洗 + 1 套备用；速干材质优先（长途可洗）
- 舒适的步行鞋（最重要！城市游日均万步）+ 凉鞋/拖鞋
- 内衣裤、袜子、睡衣
- 外套（根据目的地季节）、泳衣（海岛/酒店泳池）

### 洗漱与护理
- 旅行装洗漱用品（洗发水/沐浴露/牙膏牙刷）、毛巾
- 防晒霜（SPF 50+）、润唇膏、保湿霜
- 女性用品、隐形眼镜及护理液
- 折叠洗漱包（可悬挂）

### 健康与应急
- 常用药：肠胃药、感冒药、止痛药、过敏药、创可贴
- 处方药（原包装+处方，随身携带，不托运！）
- 急救包（绷带、消毒棉片）、体温计
- 口罩、免洗洗手液

### 其他
- 水杯/保温杯、零食、收纳袋/密封袋（装脏衣湿衣）
- 伞/雨衣、纸巾湿巾、笔（填入境卡用）、笔记本
- 少量洗衣用品（长途）

## 二、按场景加装清单

### 冬季（哈尔滨/长白山/滑雪）
- 厚羽绒服/派克大衣、保暖内衣（叠穿）、防水靴
- 手套、围巾、毛线帽、暖宝宝
- 润唇膏、高保湿霜（干冷）

### 夏季/海岛
- 轻便透气衣物、遮阳帽、太阳镜、防晒霜
- 泳衣、凉鞋、速干毛巾、防蚊液

### 登山/户外（张家界/九寨沟/徒步）
- 速干衣裤、防水夹克、登山鞋
- 登山杖、头灯/手电、压缩袜、帽子头巾
- 高热量零食（巧克力/能量棒）

### 城市游
- 轻便背包、步行鞋、雨伞、便携充电器

## 三、安检与航空规定（关键红线）

| 物品 | 规定 |
|---|---|
| 液体/凝胶/喷雾 | 随身限 ≤100ml/瓶，装 1L 透明可封袋 |
| 充电宝/锂电池 | 只能随身携带，禁托运；注意航司 Wh 限制 |
| 刀具/剪刀 | 禁随身，必须托运 |
| 打火机 | 禁托运（随身规定各航司不同，多数禁带） |
| 药品 | 原包装+处方；提前查目的地管制药物规定（部分国家禁带特定成分药） |
| 食品/农产品 | 部分国家/地区禁带生鲜、肉类、水果；出境主动申报 |
| 电脑/平板 | 安检时取出单独过检 |

## 四、打包技巧

1. **卷衣法**：衣物卷起来放，省空间+防皱
2. **收纳袋分类**：衣物/洗漱/电子分袋，拿取方便
3. **"洋葱式"穿衣**：叠穿比单件厚外套灵活（应对温差）
4. **留空 20%**：给纪念品/购物留空间
5. **短途（3-7 天）轻装**：外套+基础款 T 恤即可，百搭优先
6. **长途（7 天+）带洗护方案**：速干衣 + 少量洗衣液，路上洗
7. **贵重物品随身**：证件、现金、电子设备、贵重药品永远随身
8. **提前查天气**：出发前查目的地未来 10 天天气预报，按实际调整衣物
