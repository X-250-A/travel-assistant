## 今日知识点：

- React的基础函数：
  
  - trim()：去掉字符串的头尾的空格。
    
    - `!text.trim()` 常做空字符串检查，或者说防呆检查。语句的含义是，若字符串为空则返回true。
  
  - Date()：获取当前时间。
    
    - Date()函数一般搭配new使用。new，即构造一个对象。对于Date这种需要获取多个时间，构造多个实例的函数，用new最好。如
      
      - `const a = new Date();   // 2026-07-21 14:30:00.123
        const b = new Date();   // 2026-07-21 14:30:00.124`
  
  - toISOString()：一般跟new Date()搭配，表示生成ISO格式的时间字符串。
    
    - `const a = new Date().toISOString()` 

- Tailwind：目前主流的写css样式的方式。
  
  - `<div className = bg-blue-600 text-white">`
  
  - 像上面这个句子一样，这就渲染了一个蓝底白字的标签。
  
  - 这样的写法避免了重新写一份css文件。模块化特性更明显。
