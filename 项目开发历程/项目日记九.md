## 今日知识点：

- Typescript学习：
  - `() => void` 函数类型注解：
    - 用于函数中参数的声明，声明该参数是个函数。
    - `(text : string) => void` 像这样，就说明这个函数接收str变量。
  - `!.` 非空断言操作符：
    - 声明某个变量一定不为null / undefined，如`res.body!.getReader()` 
  - `const { value1, value2, ··· } = varied.function()` 
    - 当函数返回值为一个对象时，解构赋值可以直接提取对象中同名变量的值并赋值。或者简单理解："从对象里拆出我要的字段，一步到位" 
  - TS中";"的问题：
    - 由于typescript中有自动加分号的机制（ASI），所以大部分时候是否加";"问题不大，不过，有时候不加";"会让TS识别出错，所以尽量统一加上“;”
  - props（properties）：
    - 即一种参数/属性。在各个前端语言中作用完全一致。
    - 作用是将父组件的数据单向传递给子组件。
    - 在函数中props可以直接当形参用。
