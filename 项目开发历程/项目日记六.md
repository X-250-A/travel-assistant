## 今日知识点：

- ***python函数的“ * ”签名：（关键词-only参数）***
  
  - 单独的“ * ”，代表该函数中，“ * ”之后的参数强制用关键词传递。如：
  
  - ``` 
    async def update_trip(
        db: AsyncSession,
        trip_id: int,
        *,
        title: str | None = None,
        status: str | None = None,
        plan_data: dict | None = None,
    ):
    ```
  
  - 简单来说，就是显式写出`参数名=值` 的形式。
  
  - 用于update类函数中的好处：
    
    - 使得参数的更新具有选择性，如上述函数，若后续参数全为None，则update函数即一次简单的查询，相当于select。

- ***联合类型注解：***
  
  - 一种在函数中对参数类型进行标注的方式。python 3.10+的通用语法。依旧以上述函数为例：
  
  - ```
    async def update_trip(
        db: AsyncSession,
        trip_id: int,
        *,
        title: str | None = None,
        status: str | None = None,
        plan_data: dict | None = None,
    ):
    ```
  
  - str | None ，简单理解，可以理解为 str “或” None，即该参数类型可以是str，也可以为None（None在py中是一种类型！！！）
  
  - str | None = None，则为带默认值的联合类型注解，不传入参数时，该参数默认为None。

- ***None类型注解：***
  
  - 跟平常讲的空值差不多，但这里None是一种数据类型。
  
  - 用意是强迫开发者显式进行边界处理。



- ***判空：最常用的防bug手段***
  
  - 对于id这种重要参数，一定要判空防止意外bug。
